Step-by-step tutorial

The process below follows the uploaded Direct Action Button PDF, with a separate final verification step.

01
Change the UI

Replace the RadioButton with buttons

  1. On DatabaseTestPage, delete the RadioButton and old Send to Database button.
  2. From the Widget Palette, drag in two new Buttons.
  3. Rename them Oat Milk and Almond Milk.
  4. Optionally add a third button for Whole Milk.

Your updated screen

Oat MilkOne tap to save
Almond MilkOne tap to save
Whole MilkOptional third choice

This method replaces choosing an option and then pressing Submit with a single button tap.

02
Wire the first button

Connect Oat Milk to Create Document

  1. Select the Oat Milk button on the canvas.
  2. Open the Action Flow Editor for the button's On Tap event.
  3. Select + Add Action.
  4. Choose Backend/Database → Firestore → Create Document.
  5. Set the collection to cart.
Oat Milk (On Tap) → Create Document → cart
03
Map the fields

Use a Specific Value for Oat Milk

In the Oat Milk button's Create Document action, use + Add Field to map:

1 · user_ref

Source: From Variable

Path: Authenticated User → User Reference

2 · selected_milk

Source: Specific Value

Text: Oat Milk

Key difference: Select Specific Value for selected_milk, not Widget State. You are saving the fixed text associated with this button.

04
Repeat the action

Configure Almond Milk and other buttons

  1. Select the Almond Milk button and add the same Create Document action for cart.
  2. Set user_ref to From Variable → Authenticated User → User Reference.
  3. Set selected_milk to Specific Value → Almond Milk.
  4. If you added Whole Milk, repeat those settings but set its Specific Value to Whole Milk.

Each button writes a fixed value

Oat Milkselected_milk = "Oat Milk"
Almond Milkselected_milk = "Almond Milk"
Whole Milkselected_milk = "Whole Milk"
05
Execute and verify

Test the buttons in Firebase

  1. Check for configuration errors, then start Test Mode and sign in using a test account.
  2. Open DatabaseTestPage (or arrive there using the temporary login routing from Part 1).
  3. Tap Oat Milk, then tap Almond Milk once each.
  4. Open the Firebase Console → Firestore Database → cart collection.
  5. Check that each successful tap created a new document with the correct selected_milk text and user_ref.

First record

selected_milk: "Oat Milk"

user_ref: signed-in user's reference

Second record

selected_milk: "Almond Milk"

user_ref: signed-in user's reference

Expected result: One tap writes one new document. This exercise demonstrates direct database insertion; it does not merge duplicate items or update a quantity.
