Architecture Reference

Firestore Two-Tier Conversation Structure

To allow the AI to remember the context of an ongoing conversation, two collections work in concert: one for overall threads, and one for back-and-forth messages.

Collection Field Name Type Description & Purpose
ai_chats user_ref Document Reference (users) Identifies which authenticated user owns this conversation thread.
ai_chats conversation_id String Unique thread identifier passed directly to the AI Agent engine to restore conversational context.
ai_chat_messages chat_reference Document Reference (ai_chats) Links each individual message bubble back to its parent conversation thread.
ai_chat_messages role String Differentiates between "user" and "system" (the AI assistant).
ai_chat_messages message_text String The natural language prompt entered by user or the answer generated by the AI agent.
ai_chat_messages image_path ImagePath / String (Optional) Firebase Storage URL of any photo uploaded alongside the prompt.
ai_chat_messages sent_datetime DateTime Timestamp used to sort conversation in strictly increasing chronological order.
Phase 1

Step 1: Setting up the Native AI Agent

Configure the foundational instructions that dictate how the AI will reason and format responses without writing custom cloud functions.

01
Agent Setup · Provider

Access Native AI Agents and Select Model Provider

Navigate to the native agent builder inside FlutterFlow to start your assistant configuration.

  1. Open your FlutterFlow project and locate the AI Agents section in the left-hand navigation menu.
  2. Click + Create Agent and give your assistant a descriptive identifier (e.g., RecipeAssistantAgent).
  3. In the Provider dropdown, select your desired provider (e.g., OpenAI or FlutterFlow Native).
  4. Input your API credentials / API key when prompted to authorize direct execution.
Left Navigation Menu → AI Agents → + Create Agent → Provider: OpenAI
02
Agent Setup · Persona & Multimodal

Define System Persona and Enable Image Processing

Specify the instructions that shape the AI's personality and enable visual reasoning capabilities.

  1. Under System Message, write clear instructions defining the AI's role and rules:
    "You are a smart recipe assistant. Suggest healthy recipes based on ingredients the user provides or uploads photos of. Be encouraging, concise, and provide step-by-step instructions."
  2. Locate the Request Parameters section.
  3. Ensure both Text and Image checkboxes are enabled so the agent can accept both natural language and photos.
Important for Vision: Checking Image exposes an image URL input parameter in the Send Message action later in Step 4.
Phase 2

Step 2: Database Structure (Firestore)

Set up the dual-collection schema required to store conversation sessions and persistent message exchanges.

03
Firestore · Thread Schema

Create the ai_chats Collection

This collection represents distinct conversation sessions.

  1. Navigate to Firestore in the left sidebar and click Create Collection.
  2. Name the collection ai_chats.
  3. Add the field user_ref with Type Document Reference pointing to users.
  4. Add the field conversation_id with Type String (this identifier is required by FlutterFlow AI Agents to maintain contextual memory).
Firestore Database → Add Collection → ai_chats → Add fields: user_ref, conversation_id
04
Firestore · Message Schema

Create the ai_chat_messages Collection

This collection stores every turn of conversation (each individual user or AI message).

  1. Create a second collection named ai_chat_messages.
  2. Add chat_reference (Document Reference pointing to ai_chats).
  3. Add role (String: "user" or "system").
  4. Add message_text (String).
  5. Add sent_datetime (DateTime).
  6. Add image_path (ImagePath / String, Optional).
Firestore Database → Add Collection → ai_chat_messages → Add required schema fields
Phase 3

Step 3: Building the Chat UI

Construct a ListView chat screen with responsive left/right message bubble alignment and real-time Firestore querying.

05
UI Layout · Alignment

Construct ListView and Apply Conditional Visibility

Ensure user and assistant messages visually appear on opposite sides of the screen.

  1. Drag a ListView widget into your page body.
  2. Inside the ListView template item, add two Row containers representing:
    • User Bubble Row: Right-aligned container with primary blue background.
    • AI Assistant Bubble Row: Left-aligned container with light grey/white background.
  3. Select the User Row, enable Conditional Visibility, and set condition: role == "user".
  4. Select the AI Row, enable Conditional Visibility, and set condition: role == "system".

06
Data Fetching · Sorting

Attach Backend Query with Chronological Sorting

Stream the conversation messages in proper sequential order.

  1. Select the ListView widget and open the Backend Query tab in the right panel.
  2. Query Type: Query Collection → Collection: ai_chat_messages → Query Type: List of Documents.
  3. Add a Filter: chat_reference Equal To Active Chat Document Reference.
  4. Crucial UI Step: Under Order By, select sent_datetime and choose Increasing so earlier messages appear at the top and newly arrived messages appear at the bottom.
Warning: Omitting the Increasing sort order on sent_datetime causes replies to render randomly or invert upside-down as new documents arrive.
Phase 4

Step 4: Configuring the Logic & Actions

Wire the lifecycle actions on page load and trigger the Send Message execution chain.

07
Lifecycle Logic · Initialization

On Page Load: Check or Create Active Chat Session

Ensure that an ongoing session thread exists before the user can type or send messages.

  1. Select the root Page widget and open its Action Flow Editor under On Page Load.
  2. Add an action to query ai_chats where user_ref equals Authenticated User.
  3. Add a Conditional Action evaluating whether an active document exists:
    • TRUE (Chat Exists): Save reference to Page State.
    • FALSE (No Active Chat): Trigger Create Document in ai_chats, generate a unique conversation_id (e.g. using Random String or UUID), and assign the output reference to Page State.
Page Properties → Actions → On Page Load → Query ai_chats → Conditional Check → Create If Null
08
Action Flow · Message Chain

Send Button: Record User Message and Invoke AI Agent

Build the core 3-step action chain on your Send IconButton.

1. Create User Document Save text input to ai_chat_messages with role = "user"
→
2. Trigger AI Agent Execute Send Message with text & conversation_id
→
3. Create System Document Save AI action response with role = "system"
  1. Action 1 (Create User Message): Create document in ai_chat_messages:
    • chat_reference = Active Chat Document
    • role = "user"
    • message_text = Textfield widget state
    • sent_datetime = Current Time
  2. Action 2 (AI Agent Send Message): Under Actions, select AI Agent → Send Message. Provide:
    • Agent: RecipeAssistantAgent
    • Text Input: Textfield widget state
    • Conversation ID: Active chat's conversation_id
    • Action Output Variable Name: aiResponse
  3. Action 3 (Create System Reply): Immediately create a second document in ai_chat_messages:
    • chat_reference = Active Chat Document
    • role = "system"
    • message_text = Action Output aiResponse
    • sent_datetime = Current Time
Phase 5

Step 5: Adding Image Capabilities & UX Polish

Enable multi-modal photo analysis and ensure seamless UI state clearing after sending.

09
Multimodal Vision · Camera

Add Image Upload Control & Pass Photo URL to Agent

Allow users to upload pictures directly (e.g. snapping a picture of ingredients inside their fridge).

  1. Add an image upload IconButton (e.g. camera or paperclip icon) adjacent to your text field.
  2. Attach the action Upload / Save Media → Upload Photo/Video to Firebase.
  3. In your Send Message Action Chain (Step 8, Action 2):
    • Locate the Image Input parameter on the AI Agent → Send Message action.
    • Bind it to the uploaded media URL output variable from your upload action.
  4. In Action 1 (User Document), pass the uploaded photo URL into the image_path field.
Upload Button → Upload Media → Send Action: AI Agent → Pass Text + Uploaded Photo URL
10
UX Polish · State Clearing

Reset Input State & Clear Upload Cache

Keep the user interface clean and responsive for subsequent prompts.

  1. At the very end of your Send Message action chain, add a Clear Text Field action targeting your input widget.
  2. Add a Clear Uploaded File or Page State reset action to dismiss any uploaded image thumbnail preview.
User Experience Note: Clearing both the text input and uploaded photo preview prevents accidental duplicate submissions and ensures the input bar is immediately ready for follow-up questions.
