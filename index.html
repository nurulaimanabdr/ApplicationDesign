3. Create Your Project

  1. Log in to FlutterFlow.
  2. Click Create New Project.
  3. Name it: task-tracker-student
  4. Choose the Blank template (not a pre-built one — we build from scratch to learn).
  5. When asked about Firebase, choose to skip or set up later. We don't need it.
✅ Checkpoint: You should now see the FlutterFlow Builder with an empty page called HomePage.

4. Understanding the Widget Palette

The Widget Palette is the panel on the left side of the builder. It holds every building block you can drag onto your page.

🧠 Mental model: Think of the Palette as a box of LEGO bricks. You pick a brick, drop it on the page, then change its color, size, and spacing using the settings panel on the right.

Layout Elements

These control where things go on the page.

WidgetWhat it doesWe use it for
ColumnStacks items verticallyThe whole page below the header
RowPlaces items side by sideTitle + settings icon in the header
ContainerA styled box (background, border, spacing)Each task card
StackLayers items on top of each otherThe floating "+" button
ExpandedFills leftover spaceAround text inside cards

Basic Elements

These are the content pieces.

WidgetWhat it doesWe use it for
TextShows words"My Tasks", task names
IconShows a symbolThe settings gear, delete icon

Form Elements

These are interactive pieces.

WidgetWhat it doesWe use it for

The Golden Rule: Palette vs. Widget Tree

There are two panels you need to know:

  • Widget Palette (left, top) → your toolbox — the bricks you can grab
  • Widget Tree (left, bottom) → the actual list of what is on your page
⚠️ Remember this: When you drop a widget, it goes into whichever widget is selected in the Widget Tree. If a widget lands in the wrong place, it's almost always because the wrong parent was selected. Always select the parent in the tree first, then drag.
💡 Time saver: Use the search box at the top of the Palette to find a widget quickly.

5. Build the Main Task Page

Build in four stages: page → header → cards → button. Take your time — there's no rush, and every step is just a click.

Stage 1: Create the page

  1. Click the Page Selector at the top → + Add Page.
  2. Name it: MainTaskPage
  3. Go to Settings → App Details → set Initial Page to MainTaskPage.
  4. On the page settings, turn the AppBar OFF — we're building our own header.

Stage 2: Add the page's base

  1. Drag a Column onto the canvas.
  2. With the Column selected, open the Properties Panel (right side) and set:
SettingValue
Main Axis Sizemax
Cross Axis Alignmentstretch
Padding16 on all sides
Background ColorYour theme's surface color
  1. In the Widget Tree, rename it to mainColumn (double-click the name).
✅ Checkpoint: A full-height column now fills your page.

Stage 3: Build the header

  1. Drag a Row into mainColumn.
  2. Inside that Row, add (in order):
    • a Text widget → type: My Tasks → set font size to 28 and make it bold
    • a Spacer (drag one from the Palette) → pushes the next item to the far right
    • an Icon widget → choose the settings icon
  3. Give the Row 16px padding at the bottom.
✅ Checkpoint: Top of the page shows "My Tasks" on the left and a gear icon on the right.

Stage 4: Add a "tasks remaining" line

  1. Drag a Text widget into mainColumn, just below the header Row.
  2. Type: 3 tasks remaining
  3. Set color to a muted grey and size to 14.
💡 Why type fake text? The number is a placeholder for now. A fixed label is perfect for learning layout.

Stage 5: Build your first task card

This is the centerpiece. Follow slowly.

  1. Drag a Container into mainColumn. This is your task card. Set:
SettingValue
Padding12 on all sides
Margin0 top, 8 bottom, 0 left, 0 right
Border Radius12
Background ColorYour theme's card color
  1. Inside the card Container, drag a Row.
  2. Inside that Row, add (in order):
    • a Checkbox
    • an Expanded widget → inside it a Column
    • an Icon → choose delete_outline
  3. Inside that inner Column, add two Text widgets:
    • Text 1: Buy groceries → bold, size 16
    • Text 2: Due: Oct 12 → grey, size 13
✅ Checkpoint: One clean task card with a checkbox, title, date, and delete icon.
💡 Why Expanded around the inner Column? It lets the text stretch and wrap instead of overflowing. Overflow shows up as yellow-and-black striped bars — you'll learn to spot it instantly.

Stage 6: Copy the card for more tasks

  1. In the Widget Tree, right-click your task card Container.
  2. Choose Copy, then Paste.
  3. Paste twice so you have three cards.
  4. Edit the text in each copy so they differ:
    • Card 2: Finish report / Due: Oct 15
    • Card 3: Call dentist / Due: Oct 8
  5. On Card 3, tick the Checkbox so one card looks completed.
✅ Checkpoint: Three task cards, all with different text.

Stage 7: Add the floating "+" button

  1. In the Widget Tree, select the very top of the page.
  2. Drag a Stack and place it as the outermost widget, with mainColumn inside it.
  3. Add a second child to the Stack: a Container. Set:
SettingValue
Width56
Height56
Border Radius28 (this makes it a perfect circle)
Background ColorYour primary color
AlignmentBottom Right
Margin from edge24
  1. Inside the Container, add an Icon → choose add → set color to white.
✅ Checkpoint: A round button floats at the bottom-right, above your cards.

✅ Stage complete: You now have a beautiful, static Main Task page — built entirely with clicks.

6. Polish the Layout

These small touches make the page look professional instead of "student work."

  • Consistent spacing: Everything should have the same 16px page padding. Uneven gaps look messy.
  • Icon colors: Make the settings and delete icons a muted grey (#6B7280) instead of pure black.
  • Title weight: Keep only the page title and task titles bold. Everything else should be regular weight.
  • Choose a theme: Go to Theme Settings and pick a primary color you like — it instantly updates the "+" button and other accents.
💡 A good habit: Zoom out and look at the whole page on the canvas. If something feels off-balance, it probably is. Trust your eye.

7. Preview on a Phone

Always check your work on a phone-sized screen before calling it done.

  1. Click the Play / Preview button (top-right of the builder).
  2. Switch the preview to a phone size (e.g. iPhone or Pixel).
  3. Check that:
    • The header sits at the top
    • All three cards are visible
    • The "+" button stays at the bottom-right
  4. Then try a tablet size. If things stretch awkwardly, adjust your padding.
✅ Checkpoint: No yellow/black overflow bars in either view.
🧠 Why this matters: A layout that looks fine on a large canvas often breaks on a real phone. Previewing at phone size is the single best habit you can build.

8. Fix Common Problems

ProblemWhy it happensHow to fix
Red & yellow striped bars appearA widget can't fit inside its parentCheck for missing Expanded widgets
Widget drops in the wrong placeThe wrong parent was selected in the Widget TreeSelect the parent in the tree first, then drag
The "+" button isn't floatingStack not set as the outermost widgetMake sure the Stack contains mainColumn
Card text gets cut offInner Column not wrapped in ExpandedWrap the text Column in an Expanded widget
The page appears empty in previewInitial Page not set correctlyCheck Settings → App Details → Initial Page
Cards have uneven spacingInconsistent marginsSet every card's margin to 0 top, 8 bottom
Checkbox does nothingIt's just a visual element in a front-end buildThat's expected — a working checkbox needs data logic, a later lesson
💡 The #1 beginner error: You can't see it on the canvas, but the Widget Tree tells you everything. If something looks wrong on the page, read the tree like a paragraph — top to bottom, inside to outside.

9. Final Checklist

Before you show your work to anyone, confirm each line:

  • MainTaskPage is set as the Initial Page
  • Header shows "My Tasks" and a settings icon
  • "3 tasks remaining" line appears below the header
  • Three task cards are visible, each with a checkbox, title, date, and delete icon
  • One card is ticked as completed
  • The circular floating "+" button sits at the bottom-right
  • No yellow/black overflow bars on phone or tablet preview
  • The page uses one consistent color theme

10. Bonus Challenges

Finished early? Try these — still no coding required.

  1. Add a 4th task — copy a card and change the text.
  2. Add a divider — place a thin Divider line between two sections.
  3. Try an empty state — delete all three cards and instead show one big friendly "No tasks yet!" message in the middle of the page.
  4. Add a date picker — drop a DatePicker widget onto the page to see what it looks like.
  5. Styling pass — pick a brand-new color theme and apply it consistently.
